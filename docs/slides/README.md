# Khung thuyết trình

Tạo file PPTX ở giai đoạn chuẩn bị nộp bài, gồm:

1. Tên đề tài, nhóm và thành viên.
2. Mục tiêu và yêu cầu.
3. Kiến trúc Client–Server và sơ đồ mạng.
4. Vigenère và ví dụ minh họa.
5. Luồng xử lý, giao thức và thiết kế CSDL.
6. Demo mã hóa/giải mã, thống kê, chat và file.
7. Kết quả kiểm thử.
8. Kết luận và hướng phát triển.

Hiện chưa có file PPTX hoàn chỉnh.
