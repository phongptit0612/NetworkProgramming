# Dàn ý báo cáo

## Chương 1 — Tổng quan

1.1 Giới thiệu, lý do chọn, ý nghĩa và ứng dụng đề tài.

1.2 Mục tiêu và phạm vi.

1.3 Cấu trúc đề tài.

## Chương 2 — Cơ sở lý thuyết

Client–Server; TCP/IP; Java Socket; luồng đọc/ghi; đa luồng;
Vigenère (công thức, mã hóa, giải mã, ví dụ); JDBC và MySQL; truyền file.

## Chương 3 — Kết quả thực nghiệm

3.1 Sơ đồ thực nghiệm có hình, IP và cổng thực tế.

3.2 Yêu cầu và kịch bản thực nghiệm.

3.3 Công cụ, hệ điều hành và phiên bản.

3.4 Các bước cài đặt và chạy chương trình, ảnh thao tác.

3.5 Kết quả, bảng kiểm thử và đối chiếu yêu cầu.

## Chương 4 — Kết luận và hướng phát triển

Kết quả đạt được, hạn chế, công việc mở rộng.

## Tài liệu tham khảo

Ghi nguồn thực sự sử dụng. Tài liệu này mới là dàn ý, chưa phải báo cáo hoàn chỉnh.
